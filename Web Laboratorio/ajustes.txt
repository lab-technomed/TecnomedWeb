## 🚨 1. ERROR CRÍTICO ENCONTRADO (debes corregirlo YA)

### ❌ El botón flotante de WhatsApp usa un número INCORRECTO

```html
<!-- Botón flotante -->
<a href="https://wa.me/519XXXXXXXX" ...>
```

Pero el **formulario SÍ tiene el número correcto** definido en el JS:
```js
const WA_NUMBER = '51974629261';
```

> 🎯 **Esto significa:** el botón flotante (💬 esquina inferior derecha) **NO funciona bien**, pero el formulario de cotización **SÍ** porque usa la variable `WA_NUMBER`.

### 🔧 Solución (copia y pega):

Busca esta línea:
```html
href="https://wa.me/519XXXXXXXX"
```

Reemplázala por:
```html
href="https://wa.me/51974629261"
```


### ✏️ Para CAMBIAR un precio:
Solo edita los números `precioMin` y `precioMax` de la línea correspondiente.

### ➕ Para AGREGAR un examen nuevo:

1. Copia una línea completa, por ejemplo:
```js
{ id: 'urea', nombre: 'Urea y Creatinina', precioMin: 40, precioMax: 65, rangoEtiqueta: '41 a 70' },
```
2. Pégala **antes del último** elemento del array (ojo con las comas `,`)
3. ⚠️ **Importante:** si quieres un ícono especial para ese examen, agrégalo también en `iconFor()`:
```js
const map = {
  hemograma: '🧫',
  glucosa: '🩸',
  lipidico: '❤️',
  orina: '🚻',
  tsh: '🧠',
  vdrL: '🛡️',
  vitD: '🌞',
  hba1c: '📈',
  urea: '💧'   // 👈 agregas esta línea
};
```
Si no lo agregas, usará el ícono genérico 🧪 por defecto (no rompe nada).

### ➖ Para ELIMINAR un examen:
Borra la línea completa, incluyendo su coma al final (o la coma anterior si es el último elemento).

> ⚠️ **Regla de oro:** Cada examen debe terminar en coma `,` EXCEPTO el último del array. Si rompes esto, el sitio dejará de funcionar (error de sintaxis).

## 🔢 4. Sobre las categorías de precio (filtro)

```js
function precioCategoria(s) {
  const mid = (s.precioMin + s.precioMax) / 2;
  if (s.precioMax <= 40) return '0-40';
  if (mid <= 70) return '41-70';
  if (s.precioMax <= 100) return '71-100';
  return '101-plus';
}
```

Esto es **automático** 🎉 — no necesitas asignar categoría manualmente, el sistema la calcula sola según el precio que pongas. El campo `rangoEtiqueta` es solo **texto decorativo** que se muestra, pero no afecta el filtro real.

> 💡 **Tip:** Asegúrate que `rangoEtiqueta` combine con lo que calculará `precioCategoria()`, para que no haya inconsistencia visual. Ejemplo: si pones `precioMax: 100`, el texto debería decir `'71 a 100'`, no `'Más de 100'`.
